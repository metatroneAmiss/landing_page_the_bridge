# Landing page – Alternance Traffic Manager (The BRIDGE)

Landing page de la campagne Google Ads « Réunion d'information – Bootcamp Traffic Manager ».

- `index.html` : page d'atterrissage avec formulaire d'inscription
- `merci.html` : page de confirmation (conversion)
- `script.js` : validation du formulaire, suivi UTM / gclid, événements GA4, envoi des leads
- `style.css` : styles (responsive mobile)
- `google-apps-script.gs` : réception des leads dans Google Sheets + e-mail de confirmation
